# Autofill - Chrome Extension for Auto Form Filling

A simple tool to help fill forms and manage input data automatically. Form filler, auto-populate fields, and data management extension.

## Overview

This Chrome extension makes form filling faster and easier by storing common values and applying them when needed. Increase productivity with automatic form completion, saved form templates, and quick data entry.

## Features

- Save and reuse form data
- Automatically populate fields
- Easy setup and use
- Works only on Teletalk jobs sites

## Installation

1. Open Chrome and go to chrome://extensions
2. Enable Developer mode.
3. Click "Load unpacked" and select the package folder.
4. Load the extension.

## Usage

1. Create your first CV or saved form values and save them.
2. Use the extension to autofill forms.
3. Save time forever by reusing stored data.
